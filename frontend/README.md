# CIPRA Frontend

This directory is a placeholder for the Next.js frontend application.

## Status

The frontend scaffold is planned for a future slice (slice 3). This slice focuses on the backend foundation, shared API contract, and G-Code formatter.

## Planned responsibilities

- Drag-and-drop image upload
- Parameter control panel
- HTML5 Canvas preview of trajectories
- Download and send the final `.gcode` file

## Stack

- Next.js (React)
- TypeScript
- Shared contract generated from `shared/api-contract.json`

## Quickstart (future)

```bash
npm install
npm run dev
```
